## 1. 项目目标

为 ALE 市场部提供内网会议纪要工具:把会议录音/录像快速转成符合 ALE 规范格式的 HTML 纪要,替代人工整理,同时保证**结果可信**——模拟数据不得冒充真实结果、不完整结果必须醒目警示、行动项必须可溯源到转写原文。

## 2. 使用者与运行约束(干系人/环境)

- **使用者**:单管理员(登录后使用全部功能);无多角色、无匿名访问。
- **部署形态**:内网单实例 Docker 部署(生产 10.20.30.203:8099);浏览器为唯一客户端。
- **外部依赖**:讯飞云录音文件转写(lfasr,有每日免费额度)、LLM 服务(OpenAI 兼容或 Anthropic 协议,公网云服务或内网白名单服务)、可选本地 FunASR 转写工作机(10.10.10.144:8300)。
- **验收总目标**(引自《最终验收目标与工作移交指导》):系统能够在当前内网、单管理员、单实例的实际使用条件下,稳定处理真实会议文件;不泄露会议内容或敏感配置;不把模拟、缺失或错误内容伪装成真实结果;任务失败后可恢复和排查;新版本可安全发布和回滚;关键行为有可重复的自动化证据。

| FR-B2 | 视频/非 mp3 音频经 ffmpeg 统一转 16kHz 单声道 mp3;纯 mp3 直传;无 ffmpeg 环境跳过转码并如实提示 | 已验收 |
| FR-B3 | 任务全局串行执行,队列容量 10,队满明确拒绝(503)且不留孤文件 | R08 PASS |
