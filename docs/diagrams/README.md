# 架构与流程图(diagrams)

`.drawio` 为可编辑源;`svg/` 目录为 drawio CLI 导出的成品(GitHub 网页可直接查看,Markdown 文档内嵌的就是它)。

## 查看与编辑

- 编辑源:VS Code "Draw.io Integration" 插件 / draw.io 桌面版 / https://app.diagrams.net;
- 本机 CLI(导出用):`D:\Tools\drawio\draw.io.exe`(v31.4.5 便携版);批量重导出:对每个 `.drawio` 执行
  `D:\Tools\drawio\draw.io.exe -x -f svg -o <同名>.svg <文件>`;
- **改图先改 `.drawio` 源,再重导出 SVG**,两件一起提交。
